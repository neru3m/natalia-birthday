# Поздравление для Наталии

Готовый мобильный статический сайт для GitHub Pages.

## Публикация

1. Создайте **публичный** репозиторий на GitHub.
2. Загрузите в **корень репозитория** `index.html`, `style.css`, `script.js` и папку `images` (именно содержимое этой папки проекта, без внешней папки `birthday-natalia`).
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Ссылка: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Сайт не требует сервера; изображения включены в проект. Для отображения шрифтов используется Google Fonts, при недоступности сети включаются системные аналоги.

## Порядок

Первый экран → фото 1 → фото 2 → отдельный текст → коллаж фото 3 и 4 с пожеланием о Петербурге → коллаж фото 5 и 6 с пожеланием → коллаж фото 7 и 8 с пожеланием. Никаких дополнительных текстов и финальной кнопки-сюрприза нет.

Обновление: текст у фотографий 3–4 исправлен; декоративный фон и разные эффекты появления добавлены.

## Просмотр на телефоне

Все 8 фотографий доступны для увеличения: нажмите на фотографию, чтобы открыть её на весь экран. Перелистывайте стрелками или свайпами, закройте крестиком. Парные фотографии на узких экранах занимают примерно 95% доступной ширины и не обрезаются.

Дополнения: анимация конверта, индивидуальные появления снимков, плавный параллакс фоновых элементов и декоративный финал без текста. Для пользователей с уменьшенной анимацией эффекты отключаются.
